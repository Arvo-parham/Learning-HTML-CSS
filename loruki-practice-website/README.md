Loruki

A responsive cloud hosting landing page built with HTML and CSS.

This project was created by following the Loruki website tutorial from Traversy Media to practice modern CSS layout techniques, reusable components, and responsive web design.

Features

- Responsive design
- CSS Grid layouts
- Flexbox layouts
- Reusable utility classes
- Custom buttons and cards
- Form styling
- Mobile-friendly interface

Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
- Font Awesome
